# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-13

### Added
- Initial release of ng-recharts
- Angular wrapper components for Recharts:
  - LineChart component
  - BarChart component
  - PieChart component
  - AreaChart component
  - ComposedChart component
- ReactBridgeService for rendering React components in Angular
- Configuration-based API for chart setup
- TypeScript type definitions for all chart configurations
- Support for Angular 12+ (including standalone components)
- MIT License compliance

### Features
- Seamless integration of Recharts in Angular applications
- Type-safe configuration interfaces
- Standalone component support
- Module-based imports for Angular < 14
